# Lab Eval Practice

Practice C solutions for lab exam question papers. Each question paper has its
own folder containing standalone `.c` programs.

## Structure

| Folder | Topics Covered |
|---|---|
| [`Set-1/`](./Set-1) | Substrings, array de-duplication |
| [`Set-2/`](./Set-2) | Backtracking (combination sum), number palindromes |
| [`Set-3/`](./Set-3) | Two-pointer string manipulation, brute-force search (3-sum) |

## How to Compile & Run

Each `.c` file is self-contained. From inside a question paper folder:

```bash
gcc filename.c -o output
./output
```

## Notes

- These are practice solutions written during lab exam prep — expect
  brute-force or straightforward approaches rather than fully optimized ones.
- See each folder's README for a description of the individual problems.
