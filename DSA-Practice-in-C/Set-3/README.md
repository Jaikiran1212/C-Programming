# Question Paper 3

## 1. `reverse-vowels-in-string.c`

Reverses only the vowels within a string, keeping all other characters in
their original positions, using a two-pointer approach.

**Run:**
```bash
gcc reverse-vowels-in-string.c -o reverse-vowels-in-string
./reverse-vowels-in-string
```

## 2. `three-sum-closest.c`

Given an array of integers and a target value, finds the sum of three
elements that is closest to the target using a brute-force triple loop.

**Run:**
```bash
gcc three-sum-closest.c -o three-sum-closest
./three-sum-closest
```
