# Question Paper 2

## 1. `combination-sum.c`

Given an array of integers and a target sum, prints all unique combinations
of elements that add up to the target (backtracking / include-exclude
recursion), with special handling for zero-valued elements.

**Run:**
```bash
gcc combination-sum.c -o combination-sum
./combination-sum
```

## 2. `palindrome-number.c`

Checks whether a given integer reads the same forwards and backwards
(negative numbers are treated as not palindromic).

**Run:**
```bash
gcc palindrome-number.c -o palindrome-number
./palindrome-number
```
